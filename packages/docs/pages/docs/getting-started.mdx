# Getting Started

## Install

```bash
pnpm add @yourscope/uikit
```

## Usage

```tsx
import { ThemeProvider } from '@yourscope/uikit/theme'
import { Button } from '@yourscope/uikit'
import '@yourscope/uikit/style.css'

function App() {
  return (
    <ThemeProvider>
      <Button>Click me</Button>
    </ThemeProvider>
  )
}
```
