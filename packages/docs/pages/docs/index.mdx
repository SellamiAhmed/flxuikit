# FlxUI

Welcome to FlxUI! FlxUI is a Mantine-based component library and design system, including components, hooks, icons, and theming. It enhances development efficiency and unifies UI style and interaction experience.

## Components

FlxUI's component library is based on Mantine v7 and includes a growing set of business-specific customizations, with full support for Dark Mode. It's organized into Primitive components (layout, typography, base building blocks) and Business components (form patterns, tables, and other higher-level abstractions).

[Read More](/docs/getting-started.mdx)

### Hooks

FlxUI ships a collection of reusable React hooks that pair with the component library to handle common product logic — color scheme management, and more — out of the box.
